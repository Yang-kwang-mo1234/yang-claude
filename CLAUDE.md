# CLAUDE.md

## Git commits

- Never run `git commit` (or push, merge, or open a PR) without asking me first in that turn, even when a skill or plan says to commit (for example superpowers' writing-plans, executing-plans, subagent-driven-development, or finishing-a-development-branch). This rule overrides those skills.
- When a plan has a "Commit" step, stop at that step, show what would be committed, and wait for my answer. If I say "later", leave the changes uncommitted and continue.
